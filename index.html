O que está em jogo

E o que vai mudar de fato?

A Reforma Tributária exige que cada contador formalize, ainda este mês, a opção entre o Simples Híbrido e o Simples Convencional para todos os clientes optantes pelo Simples Nacional, ou empresas que desejam migrar para o Simples.

A opção do Simples é em setembro. Quem não decidir dentro do prazo perde a janela para escolher o regime mais vantajoso para cada cliente.
